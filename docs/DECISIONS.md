# 결정 기록

대화로 정한 것 중 코드만 봐서는 이유를 알기 어려운 것들. 최신 결정이 위에 오도록 적는다.

## 2026-11-03

### 분석 도구: GA4 (`G-P6T4ZLNN91`)
- 후보: GA4, Microsoft Clarity, GoatCounter, Cloudflare Web Analytics, Plausible, Umami, PostHog
- GA4를 고른 이유: 가장 널리 쓰이고 실시간 접속자·시간대별·유입 경로·이벤트를 무료로 볼 수 있고, **상업 용도도 무료**. 나중에 광고·후원 등 용돈벌이를 할 수 있어서(GoatCounter 무료 요금제는 비상업 전용)
- 사람들이 실제로 어떻게 노는지 보고 싶어지면 Microsoft Clarity(녹화·히트맵, 상업 무료)를 추가 검토
- GA4는 쿠키를 씀 → 광고 등을 붙일 때 짧은 개인정보 안내 문구 추가
- 공유 링크에는 UTM 꼬리표를 붙인다(카톡·인스타 인앱 브라우저가 출처를 지워 `(direct)`로 잡히는 문제). 규칙: 영어 소문자, 이름 일관, `utm_source`=어디서, `utm_medium`=형태, `utm_campaign`=게시물·이벤트
  - 예: `?utm_source=instagram&utm_medium=bio`, `instagram/story`, `kakao/chat`, `community/post`

### 저작권 표기: `© 2026 폴크닉`, 계정 링크 없음
- 폴 계정(@uz2ning_pole)과 개발자 계정(@dev.yuja_) 중 고민하다 둘 다 넣지 않기로 함
- 나중에 서비스 전용 계정(@polknic 등)을 만들면 그때 푸터에 연결
- 캐릭터·배경·음악·아이콘 모두 코드로 직접 만든 것이라 저작권 문제 없음. three.js(MIT), Jua·IBM Plex Sans KR(OFL)은 그대로 사용 가능
- 저장소에 라이선스 파일이 없으므로 코드는 기본적으로 "모든 권리 보유"(의도된 상태)

### 이름과 주소
- 서비스 이름 **폴크닉**(폴 + 피크닉). "야외 폴 연습장", "야외 폴 스튜디오"(실내 느낌), "폴짝 호수", "폴 놀이터" 등을 거쳐 결정
- 영문 표기 **polknic**: "폴카"처럼 읽혀 한글 발음과 가장 가까움. `poleknic`은 kn 묵음 때문에 "폴닉"처럼 읽히고, `pole-knic`은 하이픈 전달이 불편하고 인스타 아이디에 못 씀
- 저장소 `uz2ni/pole-3d` → `uz2ni/polknic`으로 변경. 예전 Pages 주소는 404(자동 이동 없음)
- 소개 문구는 **"온라인 폴댄스 놀이터" 하나로 통일**("호숫가에서 폴 한 바퀴"는 뺌). 뭘 하는 곳인지 드러나고 검색되는 단어라서
- 커스텀 도메인은 아직. 붙이면 저장소 이름과 무관하게 주소가 고정되고, 서브도메인은 무제한(게임 `pole.`/`www`, 나중 서버 `ws.`·`api.`, 미리보기 `dev.`). GitHub Pages는 저장소당 도메인 하나
