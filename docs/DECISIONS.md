# 결정 기록

대화로 정한 것 중 코드만 봐서는 이유를 알기 어려운 것들. 최신 결정이 위에 오도록 적는다.

## 2026-11-10

### 후원: 크티 링크
- 사업자 없이 받을 수 있는 곳 중 크티로(사용자 결정). 투네이션은 방송 후원용이고 후원자 로그인이 필요해 보였음, Ko-fi는 영어 화면·PayPal이라 한국 사용자가 중간에 그만두기 쉬움, 포스타입은 수수료가 높고 채널 운영이 따로 필요, 토스 아이디 송금 링크는 2024-08 종료
- 크티는 카드·카카오페이 결제, 후원 수수료 0%(결제 대행 수수료 3~4%는 별도), 결제 즉시 크리에이터에게 넘어가 환불 불가
- 게임 화면에 결제를 넣지 않고 링크만, 새 탭으로 열어 방 접속이 안 끊기게. 처음엔 설정 서랍 맨 아래에 뒀다가 "사람들이 잘 볼 수 있게 드러내야 함"(사용자 요청)으로 카메라 아이콘 왼쪽 "♥ 응원하기" 분홍 버튼으로(사용자 지정). 폭 1000px 미만에선 가운데 로고와 겹치고 폰은 아이콘 줄이 이미 꽉 차서, 그때만 로고 아래에 둠
- 남은 확인: 로그아웃 상태와 카톡 인앱 브라우저에서 결제 화면까지 가는지(크티가 자동화 브라우저를 막아 직접 확인 못 함)

### 알림판 → 게시판, 기술 요청 도장 뺌
- 이름을 "게시판"으로(사용자 결정). 알림판은 운영 쪽이 공지를 붙이는 느낌이고, 여기는 이용자가 방명록·기술 요청을 붙이는 곳이라 게시판이 뜻에 맞음. 코드 이름(`board*`, GA4 `board_*`)과 문서 파일 이름(BOARD.md)은 그대로
- 기술 요청의 도장(만드는 중·추가됨)은 뺌(사용자 결정). 요청만 받고, 만든 기술은 운영자 페이지에서 수동으로 완전 삭제
- 게임 화면에 코르크 게시판과 우체통 소품을 둠(징검다리 길 끝 뒤편). 게시판은 방명록, 우체통은 '운영자에게' 탭으로 엶
- 내 글 지우기는 이번 접속(새로고침 전)에 쓴 글만. 서버에 글쓴이 정보를 저장하지 않으려고 서명한 표를 메모리에만 둠

## 2026-11-09

### 알림판: 방명록·기술 요청은 공개, 문의·제안은 비공개
- 공개 글은 코르크판 포스트잇, 문의·제안은 "운영자에게" 탭. 공개되면 안 되는 글을 게시판에 섞지 않음
- 방명록 색은 고르지 않고 글 번호로, 기울기 없음. 기술 요청은 이름 20자만, 같은 이름은 하트로 합치며 합쳤다고 안내
- 하트는 접속당 글마다 1회, 다시 들어오면 또 누를 수 있음(사용자 결정). 그래서 하트 수는 사람 수가 아니라 공감 횟수
- **신고 기능은 만들지 않음**(사람 눌러 신고, 포스트잇 떼기 포함, 사용자 결정). 공개 글 관리는 금칙어 검사와 운영자 내리기뿐
- 저장은 D1 한 곳. 슬랙 무료판은 기록이 사라지므로 알림으로만 씀. 구글 시트 연동도 만들었다가 뺌: 운영자 페이지가 있으면 같은 내용을 한 번 더 보여 줄 뿐이고 연락처 사본만 늘어남
- 답장을 하려면 연락처가 필요해서 선택 입력으로 받음. 슬랙에는 안 보내고 처리 완료 또는 90일 뒤 지움

## 2026-11-07

### 간식존: 폴짝 매점
- 위치는 사용자가 스크린숏에 표시한 서쪽 벤치 왼쪽(소나무 앞, 울타리 끝). 카운터를 낮게(0.46m) 하고 직원 NPC는 발판 위에 세워야 2.5등신 직원이 카운터에 안 가려짐
- 메뉴(사용자가 정함): 아메리카노·단백질 쉐이크(초코)·이온음료·닭가슴살·탕후루. 바나나는 뺌(카운터의 바나나 그릇도 탕후루 꽂이로). 돈·재화 없이 전부 무료
- 카운터는 한 명씩(사용자 요청): 먼저 온 손님이 주문하고 받을 때까지 뒤 사람은 줄에서 대기. 서버가 방마다 줄 하나를 관리(`shop`/`unshop`). 주문하면 직원이 2.5초 만드는 시간이 있어야 기다리는 의미가 생김. 맨 앞에서 고르지 않고 버티면 웹 25초·서버 45초에 빠짐
- 산 간식은 오른손에 듦. 처음엔 4.5초마다 저절로 한 모금이었는데, 사용자 제안으로 **"한 입" 버튼을 여러 번 눌러 먹고 다 먹으면 버튼이 사라지는** 방식으로 바꿈(직접 하는 재미, 사진 찍을 때 원하는 순간에 먹는 동작). 사용자 요청으로 3입이면 끝(탕후루 알도 3개), 다 먹으면 배불러서 잠깐 활짝 웃고 원래 표정으로. 탕후루 알이 하나씩 없어지는 식으로 남은 양을 보여 줌.
- 이름: 냠냠 매점 → **폴짝 매점**(사용자 선택. 폴 위에 오를 때의 '폴짝')
- 매점 옆에 테이블 1 + 의자 3(사용자 요청). 앉으면 간식을 테이블에 내려놓고 한 입 누를 때만 집어 먹음(앉아서 먹는 느낌). 의자는 벤치 구조를 그대로 써서 서버 변경 없음 폴에 오르거나 매트에 앉으면 내려놓음(폴 동작 중에 손에 드는 건 어색해서). 다른 사람에게도 보이게 `state`의 `snack`으로 보냄

- 아이폰 실측(`?bench`)에서 41명까지 30fps 유지, 60fps 기준 환산 약 20명. 10명(안전한 출발점)을 제안했지만 사용자가 20명을 선택

### 멀티플레이 서버: Cloudflare Workers + Durable Objects, DB는 D1 (Supabase 대신)
- 이유: 방 하나 = DO 하나로 맞아떨어지고, 폴 잠금·검증·금칙어를 서버에 넣을 수 있고, 도메인도 이미 Cloudflare
- 비용 근거(1인당 초당 1.5개, 10명 방, 메시지 약 100바이트. 단가는 기억 기준이라 전환 시 확인):
  - 과금 방식이 핵심. Supabase Realtime·AWS API Gateway는 **받는 사람 기준 메시지 수**라 인원 제곱으로 늘어남(지인 테스트 10명·하루 2시간도 Supabase는 Pro 약 $45). DO는 **들어오는 메시지(20개 = 요청 1회) + 깨어 있는 DO 수 × 시간**, 내보내는 메시지는 무료. VM은 고정
  - DO 무료: 하루 요청 약 10만, 실행 시간 약 13,000 GB-s(128MB 기준 활성 방 약 29시간/일). 먼저 막히는 건 실행 시간
  - Hibernation은 조용할 때만 절약됨. 누가 움직이면(move 초당 4회) 방이 계속 깨어 있음
  - 동시 접속 최대 1,000명(방 100개) 기준 월 비용: DO(방 1개 = DO 1개) 평균 100명 약 $40~50, 평균 300명 약 $130 / DO 하나에 방 여러 개면 약 $10~20 / **Spring + Lightsail 4GB 서울 약 $24 고정**(전송 4TB 포함, 1,000명이면 한 달 약 1.5~5TB) / EC2는 트래픽 요금 때문에 $40~200
- 전환 시점: **DO 요금이 월 $25를 꾸준히 넘으면** Spring + Lightsail로. Lightsail은 공인 IP·전송량 포함 정액이라 EC2보다 쌈. WSS는 Cloudflare 프록시로 처리(서버 한 대면 ALB 불필요), RDS 대신 D1 유지
- 1만 명 규모로 가면 서버 여러 대(방 단위 배정) + 메시지 묶어 보내기·바이너리 포맷으로 트래픽을 3~5배 줄여야 함. 그때는 트래픽 포함량 큰 VPS가 가장 쌈

## 2026-11-03

### 도메인: `yujamong.com` + Cloudflare (아직 구매 전)
- 폴크닉·폴기록장 등 여러 서비스를 한 도메인 아래 서브도메인으로 운영: `polknic.yujamong.com`, `polenote.yujamong.com`, 메인 `yujamong.com`은 서비스 목록
- 구매·DNS: **Cloudflare Registrar**
  - 원가 판매라 갱신가가 안 오름, WHOIS 개인정보 보호·DNS 무료, 한국어 대시보드, 서브도메인 여러 개 관리가 편함. 비교: Porkbun(비슷한 가격, DNS 자유), Route 53(`.com` 약 15달러 + 영역당 월 0.5달러)
  - 제약: Cloudflare에서 산 도메인은 네임서버를 못 바꿈 → 도메인 전체를 Route 53으로 관리하려면 다른 업체로 이전해야 함(구매 60일 후). 서브도메인 하나만 NS 레코드로 Route 53에 위임하는 건 가능
  - 서버·DB·로드밸런서를 AWS에 둬도 문제없음: ALB는 CNAME(루트 도메인은 CNAME 평탄화), RDS는 DNS 불필요, ACM은 와일드카드 `*.yujamong.com` 확인 CNAME을 한 번 추가.
- API 주소는 `polenote-api.yujamong.com`처럼 한 단계로. `api.polenote.yujamong.com`은 와일드카드 인증서와 Cloudflare 무료 인증서가 두 단계를 덮지 못함
- 로드밸런서는 ALB 하나 + 호스트 기반 라우팅으로 여러 서비스 공유(ALB 하나당 월 2만~3만 원)
- 프록시(주황 구름): 웹·API만 켬. 인증서 확인 CNAME·메일·웹 아닌 포트는 끔. GitHub Pages(`polknic.`)는 꺼도 손해 없음(첫 인증서 발급이 실패할 수 있음). 켤 땐 SSL 모드 Full (strict), 실제 IP는 `CF-Connecting-IP`, 무료 플랜 업로드 100MB·응답 100초 제한

### 분석 도구: GA4 (`G-P6T4ZLNN91`)

- GA4를 고른 이유: 가장 널리 쓰이고 실시간 접속자·시간대별·유입 경로·이벤트를 무료로 볼 수 있고, **상업 용도도 무료**. 나중에 광고·후원 등 용돈벌이를 할 수 있어서(GoatCounter 무료 요금제는 비상업 전용)
