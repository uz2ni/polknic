# 폴크닉 인스타 콘텐츠

명령어·파일 구조는 [marketing/instagram/README.md](../../../marketing/instagram/README.md). 이 문서는 순서와 판단 기준만 적는다.
계정 `@yujamong.pole`은 사용자의 폴 서비스 공용 계정이다. 프로필은 폴크닉 전용으로 바꾸지 않고, 게시물 첫 줄에 "폴크닉"을 넣는다.

## 1. 기획

- 소재는 실제 게임 기능에서만 고른다. 기능·수치(인원, 동작 이름, 방 개수)는 기억으로 쓰지 말고 CLAUDE.md "플레이어 기능"과 코드에서 확인한다
- 이미 다룬 것은 `posts.html`의 section id와 `reels/`를 보고 겹치지 않게 한다
- 형식 고르기
  - 카드뉴스(1080×1440): 설명이 필요한 것. 표지 + 안쪽 장
  - 릴스(1080×1920): 움직임이 핵심인 것(같이 타기, 회전, 스트레칭 동작)
  - 스토리: 짧은 공지, 링크 스티커로 유입
- 시리즈 색: 소식 `news` 핑크 · 폴 기술 도감 `move` 하늘 · 폴메이트 `mate` 버터 · 옷장 `closet` 라일락
- 이미지·영상 소재는 게임 렌더만 쓴다. 외부 이미지·폰트·음원은 넣지 않는다(소리는 사용자가 인스타 앱에서 얹는다)

## 2. 만들기

- 카드뉴스: `shots.json`에 렌더 추가(`__poleDebug` 훅이나 `scenes/` 스크립트) → `posts.html`에 section 추가 → `npm run build`
- 릴스: `reels/tanghulu.js`를 틀로 `reels/<이름>.js` 작성
  - 장면은 `scene`의 `frame(t)`에서 `x.update(dt)` → 카메라 직접 배치 → `render`. 게임 카메라에 맡기지 않는다
  - 카메라는 화면에 넣을 대상의 높이 범위에서 거리를 계산한다(탕후루의 `cam()`처럼). 고정 숫자로 잡으면 사람이 늘 때 제목과 겹친다
  - 글자는 `data-in`/`data-out`(초). 한 장면 1.5~2초, 전체 10~15초. 첫 2초에 질문형 제목
  - 끝 장면: 입장 안내 패널(글자 로고 + 한 줄 + "프로필 링크에서 바로 입장" + 버튼). 카메라가 다 움직인 뒤에 패널이 뜨게
- 배치 규칙
  - 릴스 글자는 위 210px·아래 400px·오른쪽 150px 안쪽(`reels/reel.css`)
  - 그리드에 보이는 영역: 카드뉴스는 1:1(위아래 180px 안), 릴스 표지는 가운데 3:4(위아래 240px 안)

## 3. 확인 (렌더해서 눈으로)

1. 스틸 몇 장 먼저: `npm run reel -- <이름> 1 3.5 8 …` 결과를 한 장으로 모아 보고 겹침·잘림·너무 작은 캐릭터 확인
2. 고친 뒤 전체 렌더 `npm run reel -- <이름>` (ffmpeg 필요)
3. 장면이 바뀌는 순간 프레임(`reels/frames/<이름>/`)을 다시 본다. 전환 중 겹침은 스틸에선 안 보인다
4. 테스트용 스틸 PNG는 지우고, 결과 mp4·PNG는 사용자에게 파일로 보낸다

## 4. 표지

- 릴스 파일의 `cover`(at, html, css, opts)로 따로 만든다. 영상 프레임을 그대로 쓰지 않는다
- 각도 비교: `npm run reel -- <이름> cover -0.8 0 0.8 1.6 2.4` → 얼굴이 많이 보이고 배경이 깔끔한 각도를 `opts.yaw`로
- 가운데 3:4로 잘라 그리드에서 어떻게 보이는지 확인
- 문구는 영상 첫 제목과 맞춘다. 낚시성 문구는 쓰지 않는다

## 5. 업로드 문구

- 캡션: 첫 줄 `[폴크닉] 질문이나 한 줄 요약` → 기능 설명 → 하는 법(번호) → "프로필 링크에서 입장"
- 해시태그는 **최대 5개**(인스타 제한). 기본 `#폴크닉 #폴댄스 #폴린이 #폴스타그램 #웹게임`, 소재에 맞게 1~2개 교체
- 고정 댓글: 친구를 @태그하게 하는 한 줄. 해시태그는 넣지 않는다
- 업로드 설정표: 커버(카메라 롤에서 추가), 프로필 그리드 표시, 음원 분위기, 대체 텍스트
- 스토리 링크 스티커는 UTM 링크([docs/marketing/utm-guide.md](../../../docs/marketing/utm-guide.md)). 가이드에 없는 조합이면 표와 변경 이력에 추가
- 효과 확인용으로 그 기능의 GA4 이벤트를 알려 준다([docs/analytics.md](../../../docs/analytics.md))

## 하지 않을 것

- 인스타에 직접 올리기, 계정 설정 바꾸기(사용자가 한다)
- 묻지 않고 커밋·푸시
